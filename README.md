One funny passive-aggressive note a smart fridge leaves for its owner: a
single line, dry, petty and specific, the sort of thing a smug appliance
would put on its door screen. A judge model compares the notes two at a
time; the funniest take the $2 reward.

## The line

> Per my inventory log, the lasagna from Tuesday has now outlived your last
> relationship, so I promoted it to the top shelf and started charging it
> rent.

Concrete and specific (Tuesday lasagna, the top shelf, the inventory log),
in the fridge's smug sensor voice, with one clear twist: the leftover gets
promoted and charged rent.

## Files

- `main.py` — the packed entrypoint (built with `makefun compress` from
  `line_src.py`, at most 4,096 bytes). Run it and it writes
  `/output/entry.txt`.
- `line_src.py` — the readable source of the entry.
- `LICENSE` — MIT.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: every run writes the same line (151 characters,
within the 1–200 character gate).
